01 / Identity is not meaning

An integer is an address—not the concept itself.

The application owns the vocabulary and the meaning attached to each identity. ProtocolAi provides stable addressing and validation at the boundary; it does not decide what an instruction means or whether an action is permitted.

02 / Three distinct outcomes

Do not collapse uncertainty into a fake success.

Known value

Resolve to a qualified integer reference, then validate against its owning definition.

Unknown value

Preserve it as a literal. The host may retain, clarify, register, or reject it.

Undefined reference

Reject it as an invalid identity. Do not let a plausible integer bypass ownership checks.
